# ⭕❌ Zero Kata (Tic Tac Toe)

Zero Kata ka ek classic game, jisme single player aur two player dono modes hain, score tracking hai aur smooth animations ke saath khelne ka maza aata hai.

🔗 **Live Demo:** [zero-kata-tic-tac-toe.ai.studio](https://zero-kata-tic-tac-toe.ai.studio)

## ✨ Features
- 🎮 **Single Player Mode:** computer ke khilaf khelo
- 👥 **Two Player Mode:** apne dost ke saath ek hi device par khelo
- 🏆 **Score Tracking:** har round ke baad jeet/haar ka score
- 🎞️ **Smooth Animations:** achha aur responsive game experience
- 📱 Mobile aur desktop dono par chalta hai

## 🕹️ Kaise Khelein
1. Mode chuno: Single Player ya Two Player
2. Apni baari par kisi khali box par click/tap karo
3. Jo pehle apne 3 symbols (O ya X) ek line mein laga de, wo jeet jaata hai. Line horizontal, vertical ya diagonal ho sakti hai
4. Agar saare boxes bhar jayein aur koi line na bane, to game draw hota hai
